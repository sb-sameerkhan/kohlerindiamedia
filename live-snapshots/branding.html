Three things to know before quoting a number

1. Reach anywhere above campaign level is a sum, not an audience. Meta and LinkedIn each return one de-duplicated reach per campaign for the selected range, and those figures are sound. Two things break above that. A person reached on both YouTube and Meta is counted twice in any combined figure — and DV360 reports reach per line item without de-duplicating across them, so even the DV360-only figure double-counts anyone hit by both YouTube Skippable and Pinterest. So the DV360 row, the market rows and the Total row are all ceilings. Frequency inherits the same inflation and reads lower than reality; on a short range it can drop below 1, which is the arithmetic showing its working rather than a bug. Both carry a red marker in the KPI strip. If you need a defensible reach number, quote it at campaign level for Meta or LinkedIn, or at line-item level for DV360 — never the total.

2. DV360 Views mixes two different events. The Mega Campaign runs TrueView skippable alongside non-skippable Lineup, Masthead, Pinterest and Display. TrueView views only exist on skippable inventory — the Lineup and Pinterest lines report zero TrueView views while delivering large completed-view counts. Rather than show those lines as having no views at all, this dashboard falls back to completed views where TrueView is zero. Every table also carries a separate Complete Views column so you can see which basis a line is on. A DV360 VTR is therefore not one clean rate; read it by line item, not as a single blended number.

3. Views are not comparable across platforms. A TrueView view, a ThruPlay and a LinkedIn video view are three different thresholds. The overall VTR and CPV are arithmetic on numbers that do not measure the same thing — useful for tracking direction week to week, not for judging one platform against another. Compare within a platform.

How the data is pulled

  • Reach is a separate call per platform with no date dimension. Windsor returns platform-de-duplicated reach for the whole selected range that way. Summing daily reach rows would inflate it substantially, so reach does not appear in any day-on-day table — a daily reach column would be wrong.
  • DV360 needs its full field list in one call. Trimming fields while keeping TrueView views makes Windsor silently drop the non-YouTube line items, and the spend total comes out low but plausible. The call here is deliberately wide.
  • Long ranges are sliced into 10-day chunks and merged, to stay inside Windsor's timeout.
  • DV360 YouTube asset names come from a separate TrueView call that cannot be combined with line item or spend, so the YouTube Assets view shows impressions and views only — no spend column.

Publisher buys

Architectural Digest and Samsung are read live from tabs of the Cheil planning sheet. Windsor surfaces only the first table on each tab — the day-wise block — so the Plan vs Achieved block underneath is not machine-readable. Plan targets are therefore held in the dashboard's config and every achieved figure is recomputed from the same live day rows that feed Day on Day, which is why the two can never disagree. Both were reconciled against the sheet's own totals when built: Architectural Digest to the rupee, Samsung to ₹735,932.50 against a displayed ₹735,933 (the sheet rounds).

One parsing trap worth knowing, since it would be invisible if wrong: the Samsung tab writes impressions as 98.484, using a dot as a thousands separator, while the budget in that same row is ₹49,242.00 with a comma for thousands and a dot for decimals. Read naively, impressions come out a thousand times too small and entirely plausible. Integer and currency cells are parsed by different rules here, and the test suite checks both against the sheet totals.

These publishers report no reach and no views. They count toward Spend, Impressions, Clicks, CTR and CPM, and are held out of Reach, Frequency, Views, VTR and CPV. Inshorts is configured but has no sheet connected, so it contributes nothing at all.

Known gaps

  • Inshorts has no data connected — its tab shows the structure it will take, not a zero.
  • Meta ad-level reach is per-ad and de-duplicated within that ad only. It is shown as reported but not totalled, because summing it across ads double-counts.
  • LinkedIn reach is LinkedIn's own approximation and lags 24–48 hours; the most recent day often returns null.
  • Meta ad thumbnails come back empty from this account, so the Ads view shows name cards rather than creative previews.
  • The Windsor API key is embedded in this file. Fine for a local file on your machine; if this gets hosted anywhere shared, the key needs to move behind a server-side proxy first.
