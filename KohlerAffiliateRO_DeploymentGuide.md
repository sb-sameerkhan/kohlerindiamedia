# Kohler Affiliate RO Automation — Deployment Guide

## What this does

Each month, the script:
1. Reads all affiliate details from your Master Config sheet
2. Validates mandatory fields — flags incomplete affiliates (e.g. Nomadzdigital) without stopping
3. Opens each affiliate's tracker and fetches the monthly Spends figure from the Summary tab
4. Shows you a preview table and asks for approval
5. Submits the Google Form for each affiliate (pre-filled with all vendor, campaign, and amount data)
6. Polls Gmail for the generated RO PDF (up to 5 minutes)
7. Saves the PDF to Drive as `RO_AffiliateName_Month_Year.pdf`
8. Emails the PDF to the POC — or to your own inbox during testing

---

## One-time Setup (do this once)

### Step 1 — Create the Master Config Google Sheet

1. Open Google Sheets → create a new sheet (or use an existing one)
2. Recreate the layout from the Excel file:
   - **Column A**: field labels (Affiliate Name, Sheet ID, REV Share, POC Name, …)
   - **Columns B, C, D, …**: one column per affiliate
3. Sheet name must match `MASTER_SHEET_NAME` in the script (default: `Sheet1`)

> The sheet already exists? Just verify the tab name and column order match the Excel exactly.

---

### Step 2 — Open Apps Script

1. In the Master Config sheet: **Extensions → Apps Script**
2. Delete any existing code in `Code.gs`
3. Paste the entire contents of `KohlerAffiliateRO.gs`
4. Save (Ctrl+S / Cmd+S) — name the project "Kohler RO Automation"

---

### Step 3 — Discover Form Entry IDs

The script needs to know which form field corresponds to which data. Run this once:

1. In Apps Script: select function `discoverFormFields` → click ▶ Run
2. Grant the permissions it requests (Google Sheets, Forms, UrlFetch)
3. Switch back to the Google Sheet — a new tab called **"Form Entry IDs"** will appear
4. It lists each field title and its `entry.XXXXXXXXXX` ID

Then update `CONFIG.FORM_ENTRY_IDS` in the script:

```javascript
FORM_ENTRY_IDS: {
  'Title Of Document':        'entry.1234567890',   // ← paste from Form Entry IDs sheet
  'Vendor Name':              'entry.1234567891',
  // ... etc
},
```

> **If the form requires edit access**: share the form with your Google account as Editor, then re-run `discoverFormFields`.

---

### Step 4 — Create the RO Drive Folder

1. In Google Drive, create a folder: e.g. `Kohler / Affiliate ROs / 2026`
2. Open the folder → copy the folder ID from the URL:
   `drive.google.com/drive/folders/`**`1a2b3c4d5e6f…`**
3. Paste into `CONFIG.RO_DRIVE_FOLDER_ID` in the script

---

### Step 5 — Set Test Mode

In the `CONFIG` block:

```javascript
TEST_MODE:  true,            // true = safe; emails only go to TEST_EMAIL
TEST_EMAIL: 'sameer.khan@socialbeat.in',
```

Leave `TEST_MODE: true` for all testing. Flip to `false` only when going live.

## Running the Automation

### Every month

1. Open the Master Config Google Sheet
2. From the menu bar: **🔁 Kohler RO Automation → ▶ Run RO Automation**
3. A preview table appears — verify amounts, POC details, test mode indicator
4. Close the preview → click **Yes** to confirm
5. The script processes each affiliate, submits forms, collects PDFs, sends emails
6. A summary dialog shows final status

### Controlling the processing month

**Auto (recommended):** Leave `PROCESSING_MONTH: null` — the script picks the most recent month with data from each tracker.

**Manual:** Set `PROCESSING_MONTH: 'Jun 26'` to process a specific month.

Check **View → Logs** after each test for detailed output.

## Onboarding a new affiliate (future)

1. Add a new column to the Master Config sheet
2. Fill in all rows (Affiliate Name, Sheet ID, POC details, Vendor details, etc.)
3. That's it — the script picks it up automatically on the next run

## PDF not arriving in Gmail?

The RO PDF is generated by whatever system processes the Google Form (e.g. Autocrat, Form Publisher, or a Zapier/Make workflow). If the PDF doesn't appear within 5 minutes:

1. Check that the downstream automation (Form Publisher etc.) is active
2. Verify the Gmail account running the script receives the generated PDF
3. Increase `PDF_WAIT_MINUTES` in CONFIG if the system is slow

After the form is submitted but before the PDF arrives, the final status will be `FORM_SUBMITTED_PDF_PENDING`. You can attach the PDF and email manually from the Processing Log.

## Permissions the script needs

| Permission | Why |
|------------|-----|
| Google Sheets | Read Master Config, read tracker sheets, write logs |
| Gmail | Send emails, search for PDF attachments |
| Google Drive | Save PDF files to the RO folder |
| Google Forms | Discover field IDs (discoverFormFields only) |
| External URLs | Submit form via UrlFetchApp |

All permissions are requested on first run.
